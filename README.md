# ZTool

Windows 桌面启动器 + 剪贴板历史。目标是在「启动器」和「剪贴板」这两个场景独占替代 uTools，长期路线是长成一个插件平台——当前内部接口已经按插件形态留了缝，搜索和剪贴板都是它上面的插件。

## 功能

- **启动器**：搜开始菜单、系统内置应用（Store / AppX）、常用文件夹里的文件与命令
- **拼音搜索**：`jsb` 命中「记事本」，全拼 `jishiben` 和首字母 `jsb` 都行
- **应用图标**：结果行显示应用原生图标
- **剪贴板历史**：文本 + 截图，SQLite 持久化，可搜索、可固定、可回贴

## 使用

`Alt+Z` 唤出（若被占用会自动退让，以面板右下角的键caps 显示为准），或点托盘图标。

| 键 | 作用 |
|---|---|
| `↑↓` | 选择 |
| `Enter` | 打开 / 回贴 |
| `Ctrl+Tab` | 在「搜索 / 剪贴板」两个视图间切换 |
| `Ctrl+P` | 固定剪贴板条目（不参与淘汰、置顶） |
| `Delete` | 删除剪贴板条目 |
| `Esc` | 清空查询，再按一次关闭 |

剪贴板视图里可以搜索历史全文；页脚的「记录」开关是暂停记录，排除名单在 `%AppData%\ZTool\exclusions.txt`（一行一个进程名，默认已含常见密码管理器）。

## 环境

Windows 10 及以上。Releases 里是自包含的测试版，解压即跑，不需要另外安装运行时。

数据都在 `%AppData%\ZTool\`：`clipboard.db`（历史）、`images/`（截图）、`settings.json`、`exclusions.txt`。

## 开发

```
dotnet build ZTool.sln
dotnet test ZTool.sln
```

`ZTool.Tests` 覆盖匹配排序、拼音元数据（含多音字）、剪贴板去重与淘汰。UI 部分目前靠手测——自动化合成按键不触发全局热键。

设计决策与进度记录在 `.scratch/milestone-1/`。
