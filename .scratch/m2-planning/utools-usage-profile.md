## 对 M2 的预排序（草案）

**S — 便宜且有真实使用证据**
1. 面板内计算器（有当计算器用的实锤；成本极低，M1 期间可顺手做）
2. 网页搜索命令（百度/搜索引擎跳转）
3. 备忘快贴（收藏片段快贴）——与 M1 剪贴板 pinned 同族，天然衔接

**A — 有价值但有外部依赖**
4. AI 翻译（需接 API，选型待定）
5. 随机生成虚假数据（用户最爱插件，但属开发者向——适合做「插件形态」第二弹或等插件运行时）

**B — 插件时代的原生插件，不是内置功能**
正则编辑器、程序员手册、redis 工具、关闭进程、截图悬浮/取色（PowerToys 也覆盖）

**不做**：随记（DeskBox 在用）、插件开发工具（属 M3+ 插件运行时配套）

## 关键洞察：Alt+Space 的占用者

uTools 设置里呼出键就是 **Alt+Space**——与代码注释里「PowerToys Run 占用」并存（谁先注册谁持有）。**若日后用 ZTool 替代并卸载 uTools，应重新探测 Alt+Space 是否释放**，届时可把首选热键改回 Alt+Space（当前回退 Alt+Z 是既定设计）。
