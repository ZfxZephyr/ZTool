### 试用期要盯的三件事（04 Comments 有细节）

1. **来源进程归属是启发式**——排除名单是「尽力而为」，不是精确审计。误杀/漏杀随时记下来。
2. **`SendInput` 对提权窗口静默失败**（UIPI）——回贴退化成「已放回剪贴板，手贴一步」。
3. **终端类应用可能不认 `Ctrl+V`**（有的绑 `Ctrl+Shift+V`/`Shift+Insert`）——贴不出来就记一条，加兜底按键即可。

## 已确认的设计决策

- **toggle 失焦语义**：失焦 = 隐藏 + 清空查询；再次呼出为空态
- **剪贴板内容类型**：文本 + 图片（文件类二期）
- **剪贴板入口**：主面板 Tab 视图切换（搜索 / 剪贴板）为主 +「剪贴板」命令兜底；不加新全局热键
- **隐私边界**：「暂停记录」开关 + 可编辑进程排除名单（默认含 KeePass / 1Password / Bitwarden 等常见密码管理器）；不做内容启发式检测
- **固定/收藏**：进 M1。钉住条目不参与容量淘汰，视图内置顶；存储从一开始留 `pinned` 字段
- **应用索引去重**：Start Menu 条目先到先得，AppsFolder 只补名字没被占用的；AppsFolder 内部同名则按「包 AUMID > 路径/解析名 > shell 生成 id」取身份份量高的
- **结果行图标**：只给应用出真图标，文件/命令仍用 `KindMark` 字母；图标占字母槽位但 28×28 色块底衬保留（左缘节奏基准）；提取失败退回字母
- **拼音匹配**：只对纯 ASCII 字母查询触发，只作用于 `Title`；元数据只取汉字段（`Chrome 浏览器` → `llq`）；只入词库消歧后的单一读音，不并列多音；同级减固定分 100
- **索引预热**：启动后台重建，索引没热完也允许呼出（空列表优于热键无响应）；加载动画只在首次构建显示，手动「重新索引」保留旧列表不覆盖
- **结果条数**：维持 `MaxResults = 7`，不因索引变密而扩
- **插件缝（`IPanelPlugin`）**：视图贡献（一组行）+ 生命周期 + **描述式**设置项 + 键盘 + 页脚控件槽。搜索视图自己也是一个插件；宿主只认 `PanelRow` 一种行
- **剪贴板去重**：全局去重（非仅连续相同），已知内容移到顶、刷 `last_used_at`；图片按**像素哈希**去重
- **一次复制 = 一条**：有图取图、无图取纯文本；**复制文件（CF_HDROP）一条都不记**（文件类二期）
- **文本归一化**：只削结尾 CRLF/空白，正文一字不动
- **回贴**：写剪贴板 → 还原呼出前的前台窗口 → `SendInput` Ctrl+V（注入失败内容仍在剪贴板）
- **图片**：PNG 落盘，单条上限 2MB（1000×8MB 最坏 8GB 不可接受）
- **容量**：总数 1000，只淘汰最旧未固定；pin 多了允许超；刚复制的那条永不被自己淘汰
